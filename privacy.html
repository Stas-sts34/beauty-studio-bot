Политика конфиденциальности

Настоящая политика описывает обработку данных пользователей Telegram-ботом Beauty Studio Bot, предназначенным для автоматизации записи клиентов в салон красоты.

1. Какие данные обрабатываются

Бот может обрабатывать следующие данные:

  • Telegram ID пользователя;
  • имя пользователя, предоставляемое Telegram;
  • информация о выбранной услуге;
  • дата и время записи;
  • информация о переносе или отмене записи.

2. Цели обработки данных

Данные используются исключительно для организации записи клиентов, изменения и отмены записей, а также для отправки уведомлений, связанных с записью.

3. Хранение данных

Данные о записях могут храниться в Google Sheets и Google Calendar, используемых для организации работы бота.

4. Передача данных

Данные не продаются и не используются для рекламных целей. Они используются в рамках функционирования системы записи и связанных с ней сервисов.

5. Срок хранения

Данные хранятся в течение времени, необходимого для организации записей и функционирования системы, либо до их удаления администратором.

6. Контактная информация

По вопросам обработки данных можно обратиться к администратору через Telegram-бота.
